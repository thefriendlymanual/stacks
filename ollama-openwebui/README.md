# Ollama + OpenWebUI

Ollama lets you run open source models locally on your own hardware. This stack pairs Ollama with OpenWebUI which provides a self-hosted web UI to interact with local and cloud AI services.

Opitmal configuration of Ollama will depend on your specific hardware so this is mainly left as an educational exercise for the interested homelabber. Adjusting the memlimit paramater according to the RAM available on your system seems to help performance if you are running CPU only. Refer to the [Ollama Docker Documentation](https://docs.ollama.com/docker) for information on GPU support.

If you do not have sufficiently powerful hardware to run local models, you can connect OpenWebUI to the Ollama cloud API (which has a free tier) or any other OpenAI API compatible endpoint.
