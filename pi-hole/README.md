# Pi-hole

Pi-Hole is an DNS sinkhole that acts as an ad blocker for devices on your network and protects them from other unwanted content.

Pi-Hole also acts as an 'easy-mode' DNS server for your local network. This enables us to create domain A or CNAME records for our local docker using our registered domain. We need this to resolve domain names for Docker services hosted behind Traefik or another reverse proxy.
