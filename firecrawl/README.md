# Firecrawl

Firecrawl provides an API for scraping websites and extracting information into a choice of different formats. 

When self-hosted, the Firecrawl API does not require a key, which is OK in a private homelab network but should be secured if you are hosting your Firecrawl API exposed to the internet.

Firecrawl is a great compainon to n8n and can be incorporated into workflows via MCP client or standard http request node and the output can be passed to an AI agent in agent friendly markdown or json.
