# Limesurvey

Limesurvey is a leading open source online survey tool that allows the easy creation of professional surveys, questionaires and forms.

There is no official Docker image so we use adamzammit\limesurvey (formerly ascpri\limesurvey) here which is a reputable community image. 

Limesurvey can be easily paired with GLPI as an external satisfaction survey for GLPI tickets as a more advanced alternative to GLPI's built in satisfaction survey.
