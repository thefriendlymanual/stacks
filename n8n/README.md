# n8n

n8n is a powerful fair-code licensed, low code/no code workflow automation tool. It features an intuitive drag and drop interface for creating workflows and integrations to hundreds of popular apps and services. It is one of the easiest ways to get started creating AI agents from any inference provider (including local AI) and incorporating them into real processes without coding experience.
