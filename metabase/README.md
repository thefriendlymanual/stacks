# Metabase

Metabase is an open source analytics and BI platform. Includes a built in AI copilot (Metabot) and MCP server which can be used with your preferred AI inference provider or agent respectively.

Uses H2 database for small installations and Demos. Postgres is recommeded for production use, refer to Metabase Docker docs for docker compose.
